## Your task

$ARGUMENTS が空の場合は「どんなエージェント・スキルを作成または修正しますか？」と確認すること。

依頼内容に応じて委譲先を切り替えること:

- **新規作成**（「作りたい」「追加したい」）→ agent-creator-agent に委譲
- **修正**（「変えたい」「直したい」「追記したい」）→ agent-editor-agent に委譲
- 判断が難しい場合はユーザーに確認する

それぞれ以下のフォーマットで委譲すること:

```
## 依頼内容
$ARGUMENTS

## 補足
不明点があればユーザーに確認してから進めること。
```
