# カレンダー機能 実装計画

- 日付: 2026-05-03
- ステータス: 承認済み

## 依頼内容

サイドバーに新たにカレンダーリンクを追加し、カレンダー画面へ遷移するように。
カレンダー画面は、予定の登録と削除、編集が可能で月毎、日毎、週ごとで選択してカレンダーを切り替えられるように。
タスクも日毎のカレンダーの場合は表示されるようにし、マウスオーバーするとタスクの内容を表示できるようにする。

## 実装計画

### DBスキーマ変更: あり

予定（Event）モデルを新設する。

```prisma
model Event {
  id          Int      @id @default(autoincrement())
  title       String
  description String   @default("")
  start_at    DateTime
  end_at      DateTime
  created_by  String
  created_at  DateTime @default(now())
  updated_at  DateTime @updatedAt
  creator     Account  @relation("EventCreator", fields: [created_by], references: [username])
}
```

`Account`モデルに `created_events Event[] @relation("EventCreator")` を追加する。

### バックエンド実装ステップ

1. Prismaスキーマ変更 (`backend/prisma/schema.prisma`)
2. `backend/src/events/dto/event.dto.ts` — CreateEventDto / UpdateEventDto / EventResponseDto
3. `backend/src/events/repository/event.repository.ts` — CRUD操作
4. `backend/src/events/service/event.service.ts` — ビジネスロジック（作成者のみ編集・削除可）
5. `backend/src/events/controller/event.controller.ts` — REST API（GET/POST/PATCH/DELETE、JwtAuthGuard）
6. `backend/src/events/events.module.ts` を AppModule に登録
7. メッセージ定数追加 (`backend/src/common/type/message.ts`)

### フロントエンド実装ステップ

8. `frontend/src/api/eventApi.ts` — API通信層（CalendarEvent型）
9. `frontend/src/hooks/useCalendar.ts` — 状態管理フック（月/週/日ビュー切り替え含む）
10. `frontend/src/validation/eventValidation.ts` — バリデーション
11. `frontend/src/pages/CalendarPage.tsx` — FullCalendar（dayGridMonth/timeGridWeek/timeGridDay）
12. `frontend/src/components/EventModal.tsx` — 予定作成・編集モーダル（削除ボタン含む）
13. `frontend/src/components/TaskTooltip.tsx` — タスクホバー時ツールチップ
14. `frontend/src/components/Sidebar.tsx` — カレンダーリンク追加
15. `frontend/src/App.tsx` — `/calendar` ルート追加

### 技術的注意点

- `@fullcalendar/timegrid` と `@fullcalendar/interaction` を追加インストール
- 日表示のみタスクを表示（due_date を start/end に使用）
- タスクとイベントを色で区別（タスクはグレー系）
- ツールチップは Tailwind クラスのみで実装
- EventModal は既存 ConfirmModal を削除確認に再利用
- アプリの型名は `CalendarEvent`（FullCalendarの `EventInput` と区別）

### リスク・注意事項

1. **[高] FullCalendarパッケージ不足**: `@fullcalendar/timegrid` と `@fullcalendar/interaction` が未インストール。frontend-generator-agent の実装前に `npm install @fullcalendar/timegrid @fullcalendar/interaction` を実行すること。

2. **[中] CalendarEvent 型変換**: FullCalendarへ渡す際は `EventInput[]` への変換ロジックを `useCalendar.ts` 内で一元管理すること。

3. **[中] 日表示のみタスク表示**: `useCalendar.ts` にビュー状態管理を含め、`datesSet` コールバックまたはビュー切り替えイベントで現在ビュー名を検知してイベントデータを動的に組み替えること。

4. **[中] JSX.Element 禁止**: 全コンポーネントの戻り値型は省略か `React.ReactElement` を使用すること。

5. **[低] ConfirmModal 再利用**: `ConfirmModal` の現在のprops設計を確認してから利用すること。
