# サイドバー開閉ボタンの位置移動 実装計画

- 日付: 2026-07-18
- ステータス: 承認済み

## 依頼内容

サイドバーの開閉ボタンが、カレンダーの登録画面とかぶっている。
サイドバーの開閉ボタンはサイドバーの中に配置したい。

## 実装計画

### DBスキーマ変更
なし

### 実装方針

サイドバーが `w-0` になるとサイドバー内のすべてのコンテンツが隠れてしまうため、「最小幅を確保する」アプローチを採用する。

- サイドバーを閉じたとき: `sm:w-0` → `sm:w-8`（32px）に変更し、ボタンのみ見える状態にする
- コンテンツ（ナビリンク・ロゴ・ログアウトボタン）は `isOpen=false` のとき `sm:hidden` で非表示
- トグルボタンは `Sidebar.tsx` の上部に常時表示する

### 実装ステップ

1. `frontend/src/components/Sidebar.tsx` を修正
   - props に `onToggle: () => void` を追加
   - 幅クラス: `isOpen ? 'sm:w-60' : 'sm:w-8'`
   - サイドバー上部にトグルボタンを追加（`hidden sm:flex`）
   - ロゴ・ナビ・ログアウト を `isOpen=false` のとき `sm:hidden`

2. `frontend/src/components/SidebarLayout.tsx` を修正
   - `fixed` ボタン要素を削除
   - `onToggle` コールバックを `Sidebar` に渡す

## レビュー結果

- モバイルでのトグルボタン非表示を `hidden sm:flex` で維持
- `fixed` 廃止によりカレンダー等との重なりを解消
- 変更ファイル2つのみで影響範囲が小さい
- リスク: なし
